# Coral 3.0.0

本版包含自 `coral-v2.0` 以来的改动。常用操作留在当前任务旁：新建笔记默认使用当前目录，复制和删除会显示结果，草稿可以恢复，阅读中的外部更新由你决定何时加载。同时提供包含全部网页资源的 Go 独立程序。

## 自上一发行版以来

- MCP 从只读查询扩展为创建、更新和整理笔记，与网页共用文件操作、版本检查和回收站。保存前保留原文件备份，并通过知识库自己的 Git 记录网页写操作。
- 文档与编辑预览支持本地 LaTeX 公式、Mermaid 和隔离的 HTML 交互图，无需外部 CDN；嵌入的 HTML 不能访问父页面、Coral API 或外部网络。
- 增加文末上一篇 / 下一篇、阅读位置恢复、文件与文件夹重命名、笔记移动和同库引用维护，中英文版本可以一起整理与恢复。
- 后端改为 Go，Windows 可直接启动独立程序。编辑器按需加载，长文公式分批渲染；读取和搜索复用未变化内容的缓存，外部磁盘编辑仍会被识别。

## 日常操作

- 新建知识库可以直接填写中文名称，系统自动生成目录名与稳定 ID；简介选填。
- MCP 的 `create_vault` 增加可选 `display_name`，显示名称与稳定英文 ID 分开，已有 `name` 调用保持兼容。
- 新建笔记默认保存在当前目录，需要时才展开「更改位置」。添加语言版本会根据原文语言选择缺少的版本。
- 复制后显示「已复制」，失败时可重试。删除仍需确认，移入回收站后可直接「恢复」这次删除。
- 浏览器本地草稿按编辑页面分别保存。单份草稿与文档版本一致时自动恢复；存在多份或磁盘变化时提供选择。目录页提供「未保存草稿」，放弃后仍可撤销。
- 保存或丢弃恢复内容时保留其他编辑页面的原始草稿。复制同一编辑网址开启的标签页也分别保留草稿；已保存相同内容的来源草稿可在「较早草稿」中继续恢复。
- 上传结果按文件显示成功、失败原因和实际保存位置，详情按需展开。

## 阅读与整理

- 阅读页按「文件夹、当前目录的笔记、文章章节、正文」排列，三个导航栏均可一键开合并记住选择。切换中英文时不会先闪现已隐藏的栏目。
- 笔记变化后显示「笔记已更新」，点击「加载更新」才会载入；刷新内容时保留阅读位置和栏目状态。
- 中英文版本合并成一篇笔记，列表和搜索优先显示中文。英文版本默认首行缩进两个字宽，可用 `paragraph_indent: none` 关闭。
- 重命名和移动笔记时可维护同库引用，语言版本一起整理；版本冲突和同名文件仍会阻止覆盖。Web 与 MCP 共用 Go 业务逻辑，读取磁盘上的同一份 Markdown。

## 下载和升级

发行附件提供 Windows x64、Linux x64 / ARM64、macOS Intel / Apple 芯片版本，运行无需 Node.js、npm 或 Go。Windows 解压后双击 `start.cmd`；Linux / macOS 运行 `./coral`。网页与 MCP 地址分别是 `http://127.0.0.1:8300` 和 `http://127.0.0.1:8300/mcp`。

更新时保留已有的 `obsdian/`、`.coral/` 和 `config.yaml`，只替换程序与说明文件；现有 Markdown、语言关联和回收记录不需要转换。独立程序默认在自身目录保存数据，包内配置示例使用 `data_dir: "."`。从旧版 Node stdio 配置升级时，将命令改为新程序的绝对路径，参数使用 `--stdio`。

下载后可用同一发布页的 `SHA256SUMS` 校验文件。包内 `BUILD.json` 和发布附件 `manifest.json` 记录源码提交与构建信息。程序默认只监听本机，没有账号或鉴权；跨机器访问仍需带鉴权的反向代理。

源码构建需要 Go 1.26+、Node.js 22.13+ 和 npm；Node.js 只用于构建浏览器资源。Git 用于保存网页写操作的版本历史，建议安装。

## 验证范围

独立程序的运行检查覆盖 Windows x64 和 Linux x64，包括版本信息、HTTP 页面与写入、HTTP MCP 和 stdio MCP。Linux ARM64、macOS Intel 与 Apple 芯片版本完成交叉编译、归档内容和校验值检查，未在对应机器上运行验证。
